## 🚀 Что нового в версии 4.0.0 (Изоляция критического пути L0)

Версия v4.0.0 — это крупное архитектурное обновление, сосредоточенное на **оптимизации критического пути L0 с ультранизкой задержкой**:
- **Изолированный движок L0:** Модули `MouseModulator`, `HzDetector` и `ClockStabilityMonitor` теперь полностью локализованы внутри рабочего потока `hermes-pll-worker`, исключая межпоточную блокировку.
- **Атомарные состояния с выравниванием по Cache-Line:** Разделение состояний управления UI и телеметрии Worker с выравниванием по линиям кэша процессора (0% ложного распределения кэша).
- **Упакованный атомарный режим Hz:** Объединение авто/ручного режимов и частоты в единое атомарное слово для мгновенного переключения.
- **Пакетная передача телеметрии (Sub-tick Batching):** Данные телеметрии передаются раз в 8 тиков вместо каждого тика, что снижает нагрузку на шину и ЦП на ~87%.
- **Статистика стабильности за время O(1):** Вычисление среднего и стандартного отклонения времени за постоянное время O(1) с использованием скользящей суммы и суммы квадратов.

## ⚡ Быстрый старт (Рекомендуемые настройки)

Для получения максимальной производительности за 10 секунд:

1. **Запуск от имени Администратора:** Нажмите правой кнопкой на `HermesEngine-v4.0.0.exe` и выберите **Запуск от имени администратора**.
2. **Запустите движок:** На вкладке **🚀 PLL Engine** нажмите **START PLL ENGINE** (или нажмите `Alt + 1` в игре).
3. **Выберите тикрейт сервера:**
   - Для **CS2 / Valorant / Apex:** Оставьте **128 Hz (Sub-tick / High-precision)**.
   - Для стандартных серверов 64-tick: Переключите на **64 Hz**.
4. **Настройте мощность PLL:** Оставьте **⚡ PLL Power Multiplier** на `1.0x` (или поднимите до `1.2x - 1.5x` для турнирного режима).
5. **Включите системные оптимизации:** Перейдите на вкладку **⚙ System** и включите:
   - ✅ **Lock C-States & P-States**
   - ✅ **Disable TCP Nagle Algorithm**
   - ✅ **Isolate Core Affinity**
6. **Заходите в игру!** Вы сразу почувствуете более четкий отклик прицела и отсутствие микрозадержек при кликах мыши.

## 🎮 Назначение кнопок и настроек

### 🚀 Вкладка 1: PLL Engine (Синхронизация)
* **START / STOP PLL ENGINE (`Alt + 1`):**  
  Включает движок фазовой синхронизации, устанавливает системный таймер Windows на 1.00 мс и поддерживает процессор в активном состоянии.
* **Server Tick Rate (64Hz / 128Hz):**  
  Синхронизирует внутренние часы с тикрейтом сервера. 128 Гц соответствует циклу `7.81 мс`.
* **⚡ PLL Power Multiplier (0.1x .. 2.0x):**  
  Интенсивность синхронизации тактов процессора.  
  - `0.5x`: Низкое потребление ЦП (для ноутбуков).  
  - `1.0x`: Стандартный турнирный режим.  
  - `1.5x - 2.0x`: Максимальный приоритет и молниеносный отклик.

---

### ⚙ Вкладка 2: System & Power Tuners (Защита от фризов)
* **🔒 Lock C-States & P-States:**  
  Запрещает Windows переводить ядра процессора в глубокий сон. Избавляет от микрозадержек при резких движениях.
* **🌐 Disable TCP Nagle Algorithm & ACK Delay:**  
  Отключает задержку отправки сетевых пакетов, снижая сетевой инпут-лаг на 5–15 мс.
* **🎯 Core Affinity Isolation:**  
  Привязывает поток Hermes Engine к производительным ядрам (P-Cores), предотвращая перенос на энергоэффективные ядра (E-Cores).
* **⚡ MSI (Message Signaled Interrupts) Mode:**  
  Переводит USB-контроллер и сетевую карту в высокоскоростной режим прерываний MSI.

---

### 🖱 Вкладка 3: Input & Hardware Hz
* **Mouse Delta Modulator (Layer 2):**  
  Сдвигает фазовое окно вперед при резких фликах мыши для мгновенной регистрации выстрела на ближайшем тике.
* **Shot Resync / Click Interrupt (`Alt + 2`):**  
  Сбрасывает накопленный джиттер при каждом клике или нажатии горячей клавиши, гарантируя нулевую задержку первого выстрела.

---

### ⌨ Вкладка 4: Горячие клавиши (Для полноэкранного режима)
Работает во **всех полноэкранных играх** (DirectX 11, DirectX 12, Vulkan, OpenGL):
* **`Alt + 1`** ➔ Включить / Выключить движок  
* **`Alt + 2`** ➔ Синхронизация выстрела (Shot Resync)  
* **`Alt + 3`** ➔ Сброс настроек по умолчанию
